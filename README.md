# Patch Tuesday Countdown

Live at **https://patchageddon.thorsheim.net/**

Counts down to 19:00 Norwegian time (Europe/Oslo) on the second Tuesday of every month, when Microsoft publishes its monthly security updates. When the countdown reaches zero it moves on to the next month by itself, and it lists the next 12 Patch Tuesdays with week numbers and CET/CEST.

Everything runs in the browser: one static `index.html`, no build step, no data files, no tracking. The look is a homage to the Windows 95 desktop.

Microsoft releases at 10:00 Pacific time, which is normally 19:00 in Norway; in March, when the US has moved to summer time and Europe has not, it is 18:00.
